# Freelance Rate Calculator

> Never underprice your work again.

## What it does

Enter your monthly expenses, desired income, and tax rate.
Get your minimum viable rate, recommended rate, and premium rate.

## Formula

```
Minimum Rate = (Monthly Expenses + Taxes) / Billable Hours
Recommended  = Minimum Rate * 1.5
Premium Rate = Minimum Rate * 2.5
```
